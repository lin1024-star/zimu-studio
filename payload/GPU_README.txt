字幕工坊 — NVIDIA 4 GB 省显存功能

如果已经配置好显卡，本次 1.5 更新后可以继续使用，无需重复配置。
尚未配置时，在软件“翻译与识别设置”中点击“启用显卡加速”。
完成后正常选择视频、Turbo 本地模型，点“仅识别原文”。
更新软件的方法见更新包中的 README_FIRST.txt；1.5 更新本身不会启动显卡组件下载。

第一次需要联网下载约 570 MB 官方运行组件；如果原识别引擎较旧，另需约 20 MB。
建议系统盘留出至少 2.5 GB 可用空间。可点停止，下次在软件设置中点“启用显卡加速”继续。
不用安装完整 CUDA Toolkit，不用设置 PATH，不需要管理员权限。
组件仅保存于当前用户的字幕工坊数据目录，加载设置只对本软件处理进程生效。
下载失败时保留未完成部分；已验证安装的组件不会重复下载。

4 GB 显卡：自动使用 int8_float16，一次处理一段音频，保留原有逐词时间轴和 beam_size=5。
显存不足、驱动或组件不可用时会明确显示日志，自动使用 CPU 重新识别。
不会把只识别了一部分的结果当作完整字幕。切换 CPU 时还没有开始 DeepSeek 翻译。
显卡只加速本地语音识别，DeepSeek 翻译仍然使用官方云端 API。

如果显卡驱动太旧，程序可能需要你通过 NVIDIA App 更新显卡驱动；不自动安装驱动。
若不想更新，CPU 模式仍然保留。4 GB 显存是否够用还取决于其他程序的占用；请先用短片测试。

更新程序只替换本次功能涉及的程序文件，会自动保存更新前备份。
已有模型、本机设置、字幕、project.json 和 .venv 不会被更新程序覆盖。
首次配置显卡时，若 CTranslate2 版本不匹配，会在原软件自己的 .venv 内更新为 4.8.2。
API 密钥仍只在原程序运行会话内使用，不写入设置、项目或导出文件。

来源和校验：
- NVIDIA CUDA 12.8.1 redistributable：只提取 cudart 和 cuBLAS 的运行 DLL 与许可证。
- CTranslate2 4.8.2 官方 Windows wheel（必要时）：固定版本并验证 SHA-256。
- 对照实际 Windows 构建，此版本 WITH_CUDNN=OFF，不额外安装独立 cuDNN 包。
- 完整来源 URL、文件大小和 SHA-256 在 gpu_manifest.json。
- 下载缓存内保留 NVIDIA 原始许可文件。更新包不包含 NVIDIA 二进制运行库。

已验证：真实官方组件下载/哈希/解压、Windows DLL 依赖、下载中断续传、取消、损坏拒绝、
CPU 回退控制、真实离线 tiny.en 识别和原文 SRT/TXT 导出、程序文件备份与更新失败恢复。
当前构建环境没有 Windows NVIDIA GPU，未完成 RTX 3050 实机推理或性能测试。
