**它解决什么问题**：你手头有一段外语视频（日语直播、英文讲座、游戏录像……），想配上中文字幕。传统流程要经过“找工具→装环境→转格式→识别→翻译→打轴”一堆环节，对不懂技术的人很不友好。字幕工坊把整条流水线收进一个双击就能用的软件里。

**工作流程就三步**：

1. **选文件**——丢进视频/音频（或已有的 SRT 字幕）
2. **识别**——在电脑本地用语音识别模型（faster-whisper）把话转成原文字幕。这一步**完全免费、不联网**，不需要任何 API 密钥
3. **翻译 + 校对**——调用 DeepSeek 官方接口把原文翻成简体中文（翻完还会自动做一遍「中文自检」，见下）；翻译前会**弹窗告诉你预计花多少钱，确认了才执行**。之后在软件里逐条校对、统一调时长、补字幕，导出 SRT / TXT / ASS（SRT 可直接拖进 Premiere Pro，ASS 可导入自己的样式模板）

**特点**：

- **对小白极友好**：双击安装、一键修复、断点续传（下到一半断网不白下）、可以一次排队处理多个视频、遇到报错有一份 166 条的可搜索 FAQ 对着查
- **实时字幕**（2.4 新增）：主界面第 5 页「实时字幕」——对着直播、游戏、任何正在播放的声音，屏幕下方浮一条中文字幕。可拖动、暂停、换音源、调外观（透明度 / 字号 / 宽度），共用同一份术语表和你当场加的术语；这一段跑完还能**导出双语 SRT / TXT** 拿去剪辑。实测延迟中位 3.35 秒
- **英语素材也能用**（2.4 新增）：实时字幕页可选「说的语言」（日语 / 英语），英语单词之间会正常加空格；中文自检与纠正提示词按语言分两套（日语那套一个字没动）
- **识别听错能自动改对**（2.3 新增）：同一个音被写成不同汉字时，纠正表在翻译之前把日文改对（例：原音 `おしょく` 被识别成 `お食`，中文就翻成"吃饭"，而正确写法 `汚職` 是"贪污"）。表里一行一条 `错的 = 改对的`，改完立刻生效、不联网、不消耗 API。还能写「保护词」（`お職場 = お職場`）挡住误伤
- **翻完还会自查一遍**（2.3 新增）：翻译完之后「中文自检」再扫一遍中文，把**可能翻错、会让你剪错**的句子挑出来——专名听错（同一个音被写成另一个词，意思全变）、意思反了、中文不成话、前后矛盾。**你不用懂日语，看中文就能判断**。清单里双击某一条就跳到那一条，改完回来接着看下一条（跳过的会标 ✔）。默认开着，一期素材约两三分钱，不想等可以在设置里关掉。实测：脏素材 147 条抓到全部 7 处已知真错、干净素材 112 条只报 3 处且都是真问题
- **对钱包透明**：识别本地跑不花钱；翻译按 DeepSeek 官方账单计费，费用预估是硬弹窗——不点“是”绝不扣费；密钥可勾选“记住”用 Windows 账户级加密存在本机，不勾就每次现粘。**点「保存设置」就会把密钥存下来**（2.3 修：以前只在开始任务或关软件时才存，粘了容易白粘）
- **对安全较真**：所有下载文件逐字节 SHA-256 校验、只走 HTTPS、关闭一切遥测、密钥不写进任何项目文件、MIT 开源且**源码、回归测试与发布包校验清单随包附带**；本轮实际验证数量与范围见 `VALIDATION.txt`
- **对吵素材有备选**：素材里游戏音效盖过说话声时，可勾选「先分离人声再识别」——先把人声与音效拆开再识别。实测素材很吵时能多听出大量内容（极端情况下不分离几乎识别不出东西），素材安静时改善有限；代价是识别前多等约 3 倍时间，所以**默认关闭**。分离全程在本机完成，不联网、不上传
- **时间轴有体检**：翻完之后点「时间轴体检…」，它会查字幕自己的毛病（时间倒序、两条叠在一起、闪帧、太短来不及看、挂得太久、读不完、整段没字幕），列成一张能点击跳转的表，能自动修的三类（倒序 / 重叠 / 闪帧）一键修掉——**只动时间，不改一个字**。它不听音频：实测在 BGM 铺满的素材上，靠音频对齐找偏移是找不回来的（见 `更新记录.txt` 里的实测记录）
- **对国内网络友好**：模型下载失败自动切国内镜像；另提供 tiny 轻量模型档（约 0.2GB）走魔搭直连，老电脑也能用
- **对硬件宽容**：Windows 10/11 x64，纯 CPU 就能跑；有 NVIDIA 显卡会自动检测并用 4GB 省显存模式加速

**技术构成**：C# 写的“懒人安装器”（把独立 Python 环境、依赖、模型自动准备到用户目录，不动系统）+ Python/Tk 写的字幕工作台（识别、翻译、校对、导出）。用户全程不需要碰命令行。

**代价与边界**：首次安装要联网下载模型（推荐档约 0.6GB）；识别质量受模型和素材影响（嘈杂、多人、离麦远会打折扣），成片前建议人工校对；翻译费用走你自己的 DeepSeek 账户。

**适合谁**：经常处理外语视频的字幕组、切片 up 主、追外语直播/生肉内容想存档翻译的普通观众，以及“我不想配环境，就想双击出字幕”的所有人。

## 遇到问题怎么反馈

**先说一句：这个项目是给朋友用的，作者不一定天天看 GitHub。着急的话直接发邮件到 `2385203349@qq.com`，更快。**

三种途径，任选：

1. **开一个 Issue**（推荐，能留下记录）：[新建 Issue](https://github.com/lin1024-star/zimu-studio/issues/new)
   请写清楚三件事：**你做了什么、你期望什么、实际发生了什么**。有截图最好。

2. **导出诊断包给我**：软件里点「导出诊断包」，它会生成一个 ZIP。
   这个包里**不含**你的 API 密钥、视频和字幕内容（日志会自动脱敏），可以放心发出来。
   把它拖进 Issue 里即可。

3. **发邮件给作者**：`2385203349@qq.com` —— 适合急事，或者你不想用 GitHub。

**报错怎么读**：这个软件的报错是同一个格式，第一段就是它的价值所在——

```
<一句话：出了什么事>

我实际看到的是：
　· <它检查的东西> —— <实际是什么状态>
你可以这样办：
　· <照着做就能解决的动作>
```

**「我实际看到的是」那一段最关键**：它把软件当场检查到的事实摆出来了（比如「模型目录 —— 存在但是空的」）。
照着那段读，多数情况你自己就能判断是哪儿的事。反馈时把这一段一起贴上，能省好几轮来回。

```

  lib/      随包第三方库（soundcard / cffi / pycparser，实时字幕抓系统声音用）
```

## 安全与隐私设计

- 所有下载 HTTPS-only，SHA-256 逐文件锁定，断点续传带 Range 校验
- pip 安装使用 `--no-index --require-hashes --only-binary`
- 解压带路径穿越 / 符号链接防护；日志与诊断自动脱敏
- 禁用 HuggingFace / ONNX 遥测；唯一外部接口为 `api.deepseek.com`
- API 密钥默认不落盘；可选“记住密钥”时用 Windows DPAPI 账户级加密；诊断包不含密钥、视频或字幕
