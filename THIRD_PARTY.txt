What this package contains
--------------------------
This ZIP includes the application, installer source, guides, tests, the
vocal-separation model named below, and the three vendored libraries listed
under "live subtitle audio capture". The Python runtime, the pinned wheels, and
the speech-recognition model weights are downloaded from their publishers during
setup and retain their own licenses. The MIT license in this package covers
SubtitleStudio's original code and docs, not every third-party component.

Vocal separation — Kim_Vocal_2 (MDX-Net)
  Included in this package.
  From the Ultimate Vocal Remover (UVR) project by Anjok07, aufr33 and
  contributors. UVR states that its code is MIT-licensed and asks third-party
  application developers who use its models to honour the MIT license by giving
  credit to UVR and its developers. This package gives that credit here and in
  the in-app about text (payload/关于本软件.txt).
  https://github.com/Anjok07/ultimatevocalremovergui
  The MDX-Net architecture comes from KUIELab (Woosung Choi et al.):
  https://github.com/kuielab
  These weights were trained on third-party audio datasets, so the training-data
  terms may differ from the code license. This project uses them for personal,
  non-commercial subtitle work.

Live subtitle audio capture — vendored in this package (payload/lib)
  Included in this package. Used only by the realtime subtitle overlay, which
  captures the audio the system is currently playing. Each library's full
  license text ships alongside the code at payload/lib/LICENSES.txt.

  soundcard (BSD 3-Clause), Copyright (c) 2016 Bastian Bechtold
    https://github.com/bastibe/SoundCard
  cffi (MIT No Attribution), https://github.com/python-cffi/cffi
    Bundled binary module: _cffi_backend.cp313-win_amd64.pyd
  pycparser (BSD 3-Clause), Copyright (c) 2008-2027 Eli Bendersky
    https://github.com/eliben/pycparser

Speech recognition (downloaded at setup, not included in this ZIP)
  faster-whisper (MIT): https://github.com/SYSTRAN/faster-whisper
  CTranslate2 (MIT): https://github.com/OpenNMT/CTranslate2
  OpenAI Whisper model weights (MIT): https://github.com/openai/whisper

  https://huggingface.co/Systran/faster-whisper-small
  https://huggingface.co/mobiuslabsgmbh/faster-whisper-large-v3-turbo
  Model files are fetched from immutable revisions recorded in the manifest.

Python 3.13.15 x64 (PSF license and bundled component notices):
  https://www.python.org/downloads/release/python-31315/
  https://docs.python.org/3.13/license.html
  The full Windows runtime includes Tcl/Tk and pip and their notices.

PyAV and its bundled FFmpeg libraries: https://github.com/PyAV-Org/PyAV
ONNX Runtime (MIT): https://github.com/microsoft/onnxruntime
All 25 pinned wheel versions, URLs and SHA-256 hashes: source/manifest.json
Each installed distribution contains its own license/metadata where supplied.

Optional CUDA runtime/cuBLAS components and their NVIDIA license terms:
  https://developer.download.nvidia.com/compute/cuda/redist/
  The exact component versions and hashes are in payload/gpu_manifest.json.
  This package does not include an NVIDIA display driver or the CUDA SDK.

Optional Microsoft Visual C++ x64 Redistributable:
  https://aka.ms/vs/17/release/vc_redist.x64.exe
  The original Microsoft installer and its terms apply. This tool only invokes it
  if native speech recognition dependencies cannot load after installation.

The self-contained bootstrapper targets Microsoft .NET Framework 4.5 and uses
Windows 10/11's .NET Framework 4.x runtime. No third-party .NET DLLs are bundled.
