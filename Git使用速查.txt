Git 使用速查（字幕工坊）
========================================

【核心概念：三区模型】
工作区  = 你正在改的文件（就是仓库文件夹里的文件）
暂存区  = 你告诉 git“这几个文件我要存”的地方（git add 放进来）
提交历史 = 已经存档的快照（git commit 生成的，永久可回滚）

【日常改代码后必做三步】
1. git status                看状态（安全，只看不改）
2. git add .                 把所有改动放进暂存区
3. git commit -m "说明"      正式存档

【把本地改动上传到 GitHub】
git pull --rebase origin main   先拉取云端更新（有冲突时手动解决）
git push origin main            再推送到云端

【最常用的几个命令】
git status                    看当前状态（最常用，不确定就先敲它）
git log --oneline             看提交历史（每条一行，简短）
git log --oneline --graph     看历史分支图（图形化）
git diff                      看工作区改了哪些内容（还没 add 的）
git diff --cached             看暂存区里有什么（已 add 未 commit 的）

【改错了怎么办】
git checkout -- 文件名         丢弃某个文件的改动，恢复到上次存档
git reset HEAD 文件名          把某个文件从暂存区撤回来（add 反悔）
（以上只动本地，不影响 GitHub）

【提交信息怎么写（类型标签）】
feat:     新功能
fix:      修 bug
docs:     文档改动
chore:    杂项维护（改数字、改配置等）
test:     测试相关
例如：feat: 批处理队列支持断点续传
      docs: 小白指南 FAQ 增至 120 条

【两个必须记住的提醒】
1. git status 永远是安全的，它只看不改，不会删你任何东西。
2. push 前先 git status 看一眼，知道这次改了哪些文件。

【网络相关（本机特定）】
- 代理开在 127.0.0.1:7890（Clash），git 已配置走这个代理。
- 如果 push 报“连不上”，先检查代理是否开着。
- 首次 push 用浏览器 OAuth 登录过一次，凭证已记住，以后不用再登录。

【如果遇到冲突（conflict）】
1. 别慌，git 没有丢任何东西，只是停下来等你决定。
2. 冲突文件里会有 <<<<<<<  =======  >>>>>>> 标记，框出两边内容。
3. 删掉标记，留下你要的内容，保存。
4. git add 该文件
5. git rebase --continue（或 git commit）
